## Why mpvc?

<div class="grid cards" markdown="1">

- 📖 **Readable by Design**

    Manage playlists, streaming links, and volume vectors natively using clean POSIX shell pipelines that anyone can script.

- 🖥️ **One Workflow Everywhere**

    Control instances fluidly across Linux, macOS, and BSD variants over clean local UNIX socket boundaries.

- 🎯 **Only Run What Changed**

    Lightning-fast command execution layer powered entirely by zero-overhead standard coreutils utilities like `socat` and `gawk`.

- 🔗 **One Terminal, Every Tool**

    Comes with out-of-the-box integration extensions for `fzf`, standard terminal TUIs, headless media boxes, and localized MPRIS controllers.

</div>
