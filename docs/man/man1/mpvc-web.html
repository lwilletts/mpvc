NAME

mpvc-web – Web application interface for mpvc control

SYNOPSIS

mpvc-web [option]

DESCRIPTION

mpvc-web is a lightweight web interface and HTTP API wrapper for mpvc. It allows users to control an active local mpv media player instance remotely over a network interface using standard HTTP methods or a mobile-friendly browser interface.

OPTIONS

  • -c <start|stop|status> Set the mpvc-web HTTP server command. This option is required. Accepted values are start to daemonize the server, stop to terminate it, status to check is running.

  • -b

    Set the mpvc-web HTTP server bind address. Defaults to localhost.

  • -p Set the mpvc-web HTTP server port. Defaults to 8888.

  • -r Set the mpvc-web HTTP server root directory path. Defaults to /tmp/mpvc-web/root.

  • -R Set the mpvc-web HTTP server HTML auto-refresh interval in seconds. Defaults to 240.

  • -s Set the mpvc-web HTTP server SSL/TLS configurations or certificate paths. Defaults to empty.

  • -a Set the mpvc-web HTTP server to include a ytdl-archive/ repository or path tracking download history. Defaults to empty.

  • -h, --help Display the help synopsis and exit.

EXAMPLES

Start the remote controller on all local interfaces using port 8888:

$ mpvc-web --host 0.0.0.0 --port 8888

ENVIRONMENT

  • MPVC_SOCKET The default path to the mpv IPC socket if the --socket flag is omitted.

  • MPVC_WEB_PORT Defines a default network port fallback if --port is not explicitly set.

FILES

~/.config/mpvc/mpvc.conf
mpvc configuration file.
